# Folder Structure

A monorepo containing a **Rust workspace** (core, storage, network, relay) and **one Flutter app** for every platform (Android, iOS, Windows, macOS, Linux, Web).

## Responsibilities

| Folder | Responsibility | May depend on |
|---|---|---|
| `crates/core` | Pure logic: model, CRDT, sync, identity | — (platform-unaware) |
| `crates/storage` | `Storage` implementations (native & WASM SQLite) | `core` |
| `crates/net-lan` | Native `Transport` implementation | `core` |
| `crates/net-web` | Web `Transport` implementation | `core` |
| `crates/ffi` | Wires everything together & exposes the API to Dart | all crates above |
| `crates/relay` | Signaling server, **stores no user data** | `core` (message types only) |
| `app/` | UI & state; no sync logic in Dart | `crates/ffi` (via bindings) |

**Golden rule:** `core` only knows the `Storage` and `Transport` traits. Implementations are selected in `ffi` with `#[cfg(target_arch = "wasm32")]`, so CRDT and sync logic is written and tested once for every platform.
